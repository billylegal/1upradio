How to use it
  • Websites, blogs and page builders: paste the code where you want the player.
  • Notion, Carrd, Wix and similar: use their “embed” or “custom code” block.
  • Your desktop: widget apps that show a web page (for example Rainmeter on Windows, or a browser pinned small) can open the player link directly.
  • The player plays through YouTube’s own player, the same live schedule everyone hears.
